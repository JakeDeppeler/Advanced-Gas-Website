# Keyword tracking list

Paste-ready for SE Ranking's Keyword Manager, or any rank tracker.

Two rules before you start.

**Set the location, not just the country.** A rank tracker set to
"Australia" will tell you we're nowhere for *aircon installation
Pakenham*, because it's checking from a datacentre in Sydney. Set each
project to **Pakenham, Victoria, Australia** and add a second project
for **Berwick** and a third for **Cranbourne** once the first is
moving. Local results change street by street, and a tracker set to the
wrong place is worse than no tracker.

**Track mobile separately.** Most of this traffic is someone standing
next to a dead hot water tank with a phone. Desktop rankings are a
vanity metric here.

Pakenham project. A tracker sitting in Pakenham will report us doing
better in Glen Waverley than we actually are.

Don't pay to track these. Watch them in Search Console's Performance

## The trap

Rank tracking is a lagging indicator and it's addictive. The number
that actually predicts phone calls is **impressions in Search
Console**, because impressions rise before positions do, and positions
rise before clicks do.

If impressions are climbing and rankings look flat, it's working. If
rankings look flat and impressions are flat too, nothing is working
and no amount of refreshing the tracker will change it.
