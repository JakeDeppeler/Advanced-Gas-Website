2 · Page speed for phone

Google mobile-first ranks on Core Web Vitals. Targets: LCP < 2.0s, CLS < 0.05, INP < 150ms. For the aircon industry, hitting these puts you in the top 10% for speed and gives a ranking bump on top of everything else.

The 12 action items, ranked by impact

1
Compress and convert the hero team photo to AVIF Right now /team-photo.png is a raster PNG loading uncompressed. AVIF is 40-60% smaller than JPEG at the same quality. Save as AVIF + fallback WebP, both at ~85% quality. Serve via Next <Image> with priority so it preloads for LCP. Should cut hero LCP by ~1.2 seconds on 4G.
Huge
2
Preload the hero image + preconnect Google Fonts Add <link rel="preload" as="image" href="/team-photo.avif" fetchpriority="high"> in the <head>. Add <link rel="preconnect" href="https://fonts.gstatic.com" crossorigin> so the font handshake starts before the CSS parses.
Huge
3
Lazy-load every image below the fold Fixed-price card photos, service bento photos, review avatars, and the Leaflet map should all use loading="lazy". Only the hero should load eagerly. Cuts initial payload by ~2-3 MB on mobile.
Huge
4
Defer Leaflet to only load when the map scrolls into view Leaflet + tiles is ~150 KB gzipped. Wrap the ServiceAreaMap in a dynamic import with ssr: false and use an IntersectionObserver so it only loads when the user scrolls near the map section. Saves ~150 KB from initial JS.
Huge
5
Remove dead CSS from home.css and design-system.css Old hero classes (.hero__grid, .hero__bullets, .hero__eyebrow, .hero__finep) are still in the stylesheets but not used by any component. Same for old quote form classes replaced by qcard. Kills ~4-6 KB of CSS.
Solid
6
Inline critical CSS above the fold Next.js does this by default with the App Router — verify with Lighthouse that the render-blocking CSS is minimal (< 15 KB). If any stylesheet larger than 20 KB is render-blocking, split it.
Solid
7
Font subsetting — only load Latin characters Manrope, Archivo and JetBrains Mono are already loaded with subsets: ["latin"] — good. Verify only used weights are pulled (500/600/700/800/900 for Archivo — drop 500 if unused). Each weight is ~15 KB.
Solid
8
Add explicit width + height to every image Prevents CLS (layout shift) as images load. Every <img> and Next <Image> should have explicit dimensions. CSS aspect-ratio on background-image divs.
Solid
9
Vercel Edge caching + ISR on blog pages Blog posts should use ISR with a long revalidate (24 hrs). Vercel serves them from the edge globally — first byte drops to < 100 ms in Australia.
Solid
10
Serve Google Fonts self-hosted via next/font Already using next/font — this is done. Google Fonts CDN is not on the critical path. Confirmed in src/app/layout.tsx.
Done
11
Reduce animation on scroll-heavy sections The reviews marquee auto-scrolls with CSS animation — fine on desktop, wastes battery + CPU on phone. Already gated by prefers-reduced-motion, but should also pause the animation when the section is off-screen using IntersectionObserver.
Nice
12
Cloudflare in front of Vercel for AU edge Vercel's edge is already fast in AU but Cloudflare's Sydney PoP is faster still. Adds a second cache layer and DDoS protection. Free tier is enough for this site's traffic.
Nice
Verify with: Run PageSpeed Insights on the mobile tab. Target 90+ Performance score. Run WebPageTest from Melbourne, Australia location for real 4G / cable timings.
